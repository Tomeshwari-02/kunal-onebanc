About

About

I build full-stack mobile and web applications, mostly around React Native, Node.js, MongoDB, Firebase, and REST APIs.

Recently I interned at ForgeVision.ai, where I worked on software for the OptiWaste unit deployed in JW Marriott and The Lalit Delhi. I helped build application features, backend logic, API integrations, testing flows, and performance improvements for real waste-management workflows.

I like projects where software escapes the demo stage and has to work in the real world. Gesture Genius came from that instinct: an AI-based multimodal system for hands-free gaming and Windows control using gesture, eye-gaze, head, and facial tracking. BlueChat is the other side of that curiosity: an offline Bluetooth messaging app with relay support and end-to-end encryption.

Right now I’m studying Computer Science & Engineering (Data Science) at Shri Shankaracharya Technical Campus, Bhilai, while sharpening my full-stack skills through open source, hackathons, and practical builds like this iPhone-style portfolio.

Developer notes I’d keep pinned.

01

Build for humans first.

The cleanest code is the one that makes the user forget software is in the way.

›
02

Small details compound.

A 100ms delay, a rough edge, or a confusing label can decide whether a product feels alive.

›
03

Debug the assumption.

Most bugs are not in the syntax; they are in the story you told yourself too early.

›
04

Ship, then sharpen.

Perfect plans teach less than real users, real errors, and real feedback.

05

Write it so the next developer can trust your intent before they trust your implementation.
