# Interactive Phone Portfolio UI

A sleek, interactive mobile OS & phone mockup portfolio built with vanilla HTML, CSS, and JavaScript.

## Features
- 📱 Interactive smartphone simulator UI
- 🎵 Music Player & TV App
- 🎮 Game Center & Steam stats
- 🖼️ Gallery & Photo viewer
- 📄 Interactive Resume viewer
- ⚡ Smooth animations, responsive touch & glassmorphism design

## Deployment
This project is static and can be deployed directly with Vercel, GitHub Pages, or Netlify.
